LuxCode 是一个 Python 编写的 AI 编程助手。它将 Anthropic、OpenAI 与兼容接口统一为流式 Agent 运行时，让模型能够读写代码、执行命令、调用 MCP/Skills、拆分子任务，并在权限、沙箱、会话恢复和上下文压缩机制下持续工作。

What it does

它不是聊天壳，而是一套 Agent 运行时

LuxCode 的核心价值在于把“模型回复”扩展成可循环执行的工程过程：理解工作区、选择工具、接受权限裁决、并发执行、回填结果，然后继续推理，直到任务完成。

Implementation deep dive

关键功能是怎么实现的

切换主题查看每条主干机制。右侧代码是为了表达结构而整理的等价伪代码，文件路径指向真实实现。

事件驱动、流式并发、直到完成

  • StreamCollector 把供应商流统一成文本、思考与完整工具调用。
  • StreamingExecutor 一收到完整工具参数就提交异步任务，让工具运行与剩余模型输出重叠。
  • 权限结果为 ask 的调用暂存，流结束后逐个弹窗，避免多个交互请求互相覆盖。
  • 遇到 max_tokens 会先提高输出上限，再通过续写消息进行有限次恢复。
  • 模型不再调用工具时触发 LoopComplete，否则结果回填后进入下一轮。

两层压缩 + 两类长期信息

  • Layer 1：超预算的工具输出写入会话目录，原位置替换为短预览和文件地址。
  • Layer 2：依据 Provider 的 context window 动态计算阈值，把较早轮次总结为 CompactBoundary。
  • RecoveryState 记录最近读取的文件与激活的 Skill，摘要后追加恢复附件，降低“压缩失忆”。
  • MemoryManager 维护用户级和项目级记忆；Recall 在主 LLM 调用旁路预取相关记忆。
  • SessionManager 使用 JSONL 追加消息，并可验证工具调用/结果链后恢复会话。

从策略判断到内核隔离

  • PermissionMode 先给出按工具类别的默认策略，例如 default、accept-edits、plan。
  • DangerousCommandDetector 分析 shell 命令，识别高风险形式；RuleEngine 从三层 permissions YAML 匹配 allow/deny/ask。
  • PathSandbox 限制文件路径与工作区边界，并允许 plan 模式唯一写入计划文件。
  • Sandbox 是更底层的可选执行包装：macOS 使用 Seatbelt，Linux 使用 bubblewrap。
  • Windows 当前没有 OS 级实现，会退化为权限与路径层防护。

两种并发抽象，各自解决不同问题

  • AgentTool 解析 Agent Markdown 定义、选择模型与工具集合，可 fork 当前对话，也可在临时 worktree 中运行。
  • TaskManager 管理后台任务状态与通知；TraceManager 保存父子执行树。
  • TeamManager 管理长期成员、共享任务和邮箱，可选 in-process、tmux 或 iTerm2 后端。
  • Coordinator mode 会过滤 Lead 的写工具，让 Lead 只分解与调度、由队友执行。
  • TeammateProgress 将工具活动汇总给 TUI 中的实时队友树。

工具、MCP、Skills 与 Hooks 共用边界

  • ToolRegistry 统一注册、禁用和按协议导出 schema；deferred 工具先不进入上下文，由 ToolSearch 按需发现。
  • MCPManager 连接多个 stdio/HTTP 服务器，把远程 schema 动态包装为 Pydantic Tool。
  • SkillLoader 扫描用户级与项目级 SKILL.md，SkillExecutor 参数替换后激活到环境上下文。
  • HookEngine 在 session/turn/tool 等生命周期事件上运行 command、prompt、HTTP 或 agent 动作。
  • 所有能力最终都通过标准 ToolResult 或 system reminder 回到 Agent 对话。

同一事件流，三种消费方式

  • LuxCodeApp 监听 AgentEvent，增量渲染文本、thinking、工具块、用量、权限请求与压缩通知。
  • ChatInput 实现历史记录、Slash 补全与 @file 引用展开；命令经 CommandRegistry 分发。
  • RemoteServer 把同一批事件转成 JSON WebSocket 消息；内嵌 HTML 完成 Markdown、折叠工具块和权限交互。
  • -p stream-json 把事件输出成 NDJSON，便于脚本或上层应用消费。
  • NoAltScreenDriver 去掉备用屏切换码，使 TUI 历史保留在终端 scrollback。

1. 准备配置
